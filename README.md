# Habitat Capital

Gestión básica de inmuebles (casas y apartamentos) y contratos de arriendo / compraventa.

## Estructura
- `index.html`: estructura de la página.
- `css/styles.css`: estilos, animaciones y modo oscuro.
- `js/datos.js`: datos de ejemplo y carga/guardado en localStorage.
- `js/utils.js`: utilidades (toast, etiquetas, ayudas).
- `js/vistas.js`: lista de inmuebles (pestañas) y detalle.
- `js/contratos.js`: formulario, plantillas de contrato, vista previa en vivo, firma.
- `js/navegacion.js`: cambio de pestaña con óvalo animado.
- `js/main.js`: arranque y cabecera que se oculta al hacer scroll.

## Uso
Abre `index.html` en el navegador. No necesita instalación.
"Descargar PDF" abre la impresión: elige "Guardar como PDF".
